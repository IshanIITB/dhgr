Protein design with tree search, structure prediction and logic

A draft idea: Using supervised learning is not always possible, we can use clustering to find properties we never knew existed and currently we will use reinforcement learning using Monte Carlo Tree Search.

MCTS

Role: the search. Monte Carlo Tree Search decides which partial designs deserve more effort, so expensive scoring is spent on promising branches instead of random ones. A generative model supplies the likely next moves.

Why it could help: it prunes dead ends early and keeps several branches alive, which gives diverse candidates and better use of a fixed compute budget.

Bottleneck: it is sequential and can be slower than massive parallel sampling unless evaluation is batched. Strong baselines such as evolutionary search and Bayesian optimization may match it.

AlphaFold

Role: this is a model made by google deepmind which can be used alone with first order logic help or with Monte Carlo trees as the reward system. Structure predictors score whether a designed sequence folds and binds as intended.

Why it could help: predictor confidence is currently the strongest practical signal for fold and interaction quality, and it is far cheaper than lab testing.

Bottleneck: while this does help us by giving proteins without labs being needed, it sometimes can give impossible results. A high score is not proof that a design works. AlphaFold 3 is restricted, so open models are needed for high-volume scoring.
